Resumen Flutter y Dart

Conceptos Básicos de Flutter y Dart

SDK

Es un conjunto de herramientas que ayuda a desarrollar aplicaciones. Flutter usa un SDK para crear apps móviles.

Comandos Eficientes

Son instrucciones rápidas en la terminal para ejecutar, compilar y administrar proyectos de Flutter y Dart.

Desarrollo Mobile

Es la creación de aplicaciones para dispositivos móviles como Android e iPhone.

Dart

Lenguaje de programación usado por Flutter para crear aplicaciones rápidas y modernas.

Widgets

Son los elementos visuales de Flutter, como botones, textos e imágenes.

StatefulWidget

Widget que puede cambiar su información en pantalla mientras la aplicación se ejecuta.

StatelessWidget

Widget estático que no cambia su contenido después de mostrarse.
